# Robot explorateur 3D  Semaine 9

Projet pédagogique pour Unity 6000.2.5f1.

## Démarrage

1. Ajouter ce dossier dans Unity Hub.
2. Ouvrir le projet avec Unity 6000.2.5f1.
3. Attendre la compilation.
4. Utiliser `Outils > Semaine 9 - 3D > Construire le prototype jouable`.
5. Ouvrir la scène générée dans `Assets/Semaine8_Generee/Scenes` si nécessaire.

Le constructeur reprend le niveau de la Semaine 8 et ajoute le contrôleur Rigidbody, la caméra suiveuse, la collecte, le gestionnaire, la porte, la zone dangereuse et l'interrupteur activé avec E.

Les étudiants doivent réaliser leur propre variante manuellement avant d'utiliser le constructeur comme outil de vérification.
